Renders a Lucide icon (rounded 2px stroke) — use for every glyph in Sprout UI; requires the Lucide UMD script on the page.
```jsx
<script src="https://unpkg.com/lucide@0.460.0/dist/umd/lucide.min.js"></script>
<Icon name="pill" size={20} />
<Icon name="calendar-days" color="var(--brand)" />
```
- Default stroke 2, size 20. Use 22–24 in tab bars, 16 inside small buttons/badges.
