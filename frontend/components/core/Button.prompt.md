Pill-shaped action button — use primary for the one main action per screen (e.g. "Dispense"), secondary/soft for everything else.
```jsx
<Button icon="sparkles" size="lg" fullWidth>Dispense 3 pills</Button>
<Button variant="secondary" icon="camera">Scan a label</Button>
```
- Variants: primary, secondary, soft, ghost, danger. Sizes: sm 36 / md 44 / lg 56.
- Presses scale to .97 with an inset shadow.
